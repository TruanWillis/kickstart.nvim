Collisions worth remembering

Where two plugins want the same key, the one that registers last wins — and in a few places that quietly shadows something you'd expect to work.

treesitter takes over three built-in bracket motions. ]l/[l (location list), ]a/[a (arglist) and ]s/[s (misspelled words) now move between loops, parameters and scopes. Use :lnext / :lprev and :next / :prev instead. Losing ]s matters most — with spell check on, that was how you jumped between misspellings, and toggling spell won't bring it back.
al / il mean loop, not mini.ai's "last". mini.ai's own docs say al, but treesitter wins in any buffer with a parser — so the "last" variants were remapped to aL / iL in lua/plugins/mini.lua. an / in are untouched.
Go-to-definition is <C-]>, not gd. gd isn't mapped at all. <C-]> is Vim's native tag jump, which reaches the language server because Neovim sets tagfunc. <C-t> jumps back.
LSP only starts for Lua and Python. nvim-lspconfig is ft-limited. A Go or JavaScript file gets treesitter highlighting but no diagnostics, completion or hover. To add one, the server goes in both mason-tool-installer's list (mason package name, e.g. lua-language-server) and vim.lsp.enable (lspconfig name, e.g. lua_ls).
